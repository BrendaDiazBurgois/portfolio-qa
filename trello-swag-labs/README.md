# Trello — Swag Labs QA

This repository/document contains the test documentation for the Sauce Demo application. It includes:

**Test Scenarios**
High-level test scenarios describing the application's critical features and flows.

**Test Cases**
Detailed test cases with specific steps, input data, expected results, and acceptance criteria.

**Bugs / Defects**
Bug reports detected during scenario and test case execution, including:
- Preconditions and test environment (OS, browser, version)
- Test data (users, passwords, scenarios)
- Steps to reproduce
- Expected vs. actual result
- Bug type (UI/UX, functional, data, etc.)
- Relationships between bugs when applicable
- Visual evidence (screenshots or links to Trello)

The goal of this repository is to demonstrate QA competencies, including test planning, execution, test case documentation, and bug reporting, following professional best practices.
